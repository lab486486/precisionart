# 워드프레스 지시글 작성 가이드 (필독)

자동화 스크립트가 정보를 정확하게 파악할 수 있도록, 워드프레스에서 글을 쓰실 때 아래 형식을 지켜주세요.

## 1. 기본 형식
워드프레스의 `영화지시` 카테고리에 새 글을 작성합니다.

```text
영화제목: 인간중독
개봉연도: 2014

타임라인:
00:45:12 송승헌과 임지연의 첫 만남 (이미지: https://example.com/scene1.jpg)
01:15:30 관사에서의 비밀스러운 시간 (이미지: https://example.com/scene2.jpg)
01:50:00 빗속에서의 마지막 인사

메모:
- 전체적으로 애틋하고 격정적인 분위기를 강조해줘.
- 관객수는 약 144만 명이었던 점을 참고해줘.
```

## 2. 작성 요소 상세 설명

| 요소 | 설명 | 필수 여부 |
| :--- | :--- | :---: |
| **영화제목** | 정확한 영화 제목을 입력하세요. (제목 규칙 생성에 사용됨) | 필수 |
| **개봉연도** | 4자리 숫자로 입력하세요. | 필수 |
| **대표 이미지** | 워드프레스 특성 이미지(Featured Image)로 설정하거나, 본문 첫 줄에 이미지를 삽입하세요. | 권장 |
| **타임라인** | `시간 설명 (이미지: URL)` 형식을 권장합니다. 이미지가 없다면 시간과 설명만 적으셔도 됩니다. | 필수 |
| **메모** | Gemini에게 특별히 요청할 사항이나 영화 정보를 추가로 적어주세요. | 선택 |

## 3. 꿀팁: 애드센스 수익 극대화 전략 (전면 광고 등)

사용자님께서 말씀하신 "사람들이 그냥 슬쩍 보고 나가는 것"을 방지하고 수익을 높이기 위한 추천 설정입니다.

1.  **아코디언 클릭 유도**: 스크립트가 생성하는 `명장면 타임라인`은 아코디언 방식입니다. 사용자가 구체적인 시간을 확인하기 위해 **반드시 클릭**하게 설계되어 있습니다. 이 클릭 시점에 광고가 노출되도록 워드프레스 광고 플러그인(예: Ad Inserter)을 설정하는 것이 좋습니다.
2.  **전면 광고(Vignette Ads)**: 구글 애드센스의 자동 광고 설정에서 '전면 광고'를 활성화하세요. 사용자가 페이지를 나갈 때나 다른 글로 이동할 때 노출되어 수익률이 가장 높습니다.
3.  **중간 광고 삽입**: 아코디언 섹션 바로 위나 아래에 '수동 광고 단위'를 배치하여, 타임라인을 확인하려는 사용자의 시선이 머무는 곳에 광고를 노출시키세요.
4.  **이미지 지연 로딩(Lazy Load)**: 아코디언 안에 이미지를 넣으면, 사용자가 클릭하기 전까지는 이미지가 로드되지 않아 페이지 속도가 빨라지고, 클릭했을 때의 사용자 경험을 개선할 수 있습니다.
